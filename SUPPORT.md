# Support

Choose the repo that owns the fault:

| Fault | Report it at |
|---|---|
| Home Assistant install, start, stop, update, backup, restore, mounts, or app image | [srcfl/home-assistant-addons](https://github.com/srcfl/home-assistant-addons/issues) |
| FTW Core, web UI, API, safety, dispatch, or state | [srcfl/ftw](https://github.com/srcfl/ftw/issues) |
| Optimizer protocol, solve, or plan output | [srcfl/ftw](https://github.com/srcfl/ftw/issues) |
| Managed or bundled device driver | [srcfl/device-drivers](https://github.com/srcfl/device-drivers/issues) |
| Security flaw | Follow [SECURITY.md](SECURITY.md); do not open a public issue |

Attach the Home Assistant Supervisor version, host architecture, FTW app
version, Core and Optimizer versions, the app log, and the failed step. Remove
tokens, passwords, serial numbers, and site data first.

Community support is best effort and has no service target. Paid Sourceful
support uses its own contract and route.
